# Wisp Plan 2: Vault, Lunchboxes, Old Age and His Voice

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish plan 1's leftovers. Then add:
- the ViiBR Vault and member lunchboxes;
- Old Fogey, the coal farewell and the Last Ember gift;
- Wisp's AI voice, which grows with his stage.

**Architecture:** This plan builds on the plan 1 branch `wisp-core` and keeps its layering:
- **Pure rules** live in `wisp/`. Life gains an Old Fogey stage and a PASSED ending. Voice prompt building and reply cleaning are pure functions in `wisp/voice.py`.
- **Storage** lives in `db/`. New: `keepsakes` and `notes` tables, Vault columns in `settings`, and a `from_coal` flag in `lives`.
- **Discord** lives in `cogs/`. The Studio forum loses The Lunchbox and The Billboard, and gains The ViiBR Vault, whose pinned card is the leaderboard and carries Shop and My Lunchbox buttons.
- **AI** goes through a provider chain in a new `ai/` package, in this order: Gemini, Gemini fallback model, Groq, OpenRouter. It uses aiohttp, which discord.py already installs. When every provider fails, Wisp says a pre-written line and staff get a plain error.

**Tech Stack:**
- Python 3.13, discord.py 2.6.4, aiohttp (comes with discord.py);
- aiomysql against MariaDB 11.2;
- pytest with pytest-asyncio against the real database, using `wisptest_` tables;
- black, isort, flake8, mypy --strict.

**Spec:** `DOCS/wisp_tamagotchi.html` (version 24). It is authoritative. `WispTamagotchiDesign.md` is stale.

**Ledger:** `.superpowers/sdd/2026-10-22-wisp-plan-2/progress.md`. Plan 1's ledger (`.superpowers/sdd/2026-10-20-wisp-core/progress.md`) holds the deferred minors the final review triages.

## Rulings made while planning

Copy these into the ledger when the build starts.

- **Schema changes edit `_DEFINITIONS` in place.** On 2026-10-22 all seven live `wisp_` tables held 0 rows. The bot has never been set up in a server. Before the first live run, the controller re-checks that they are empty and drops them, so `create_tables` builds the current schema. `_ADDED_COLUMNS` keeps only `best_rhyme_score`. Cost if wrong: one ALTER per column.
- **"Half warm" coal egg.** The egg starts with half the hatching food (`COAL_EGG_FOOD = EGG_FOOD_NEEDED // 2`). A fresh egg already shows 100% warmth, so a head start on hatching is the only reading that makes it warmer than usual. Cost if wrong: one constant.
- **Old Fogey timing.**
  - An Adult or Rockstar becomes Old Fogey once age reaches day 45. A late bloomer still below Adult keeps growing normally and never grows old early.
  - The farewell comes only to an Old Fogey, at day 60.
  - Becoming Old Fogey does not change `peak_stage`, so "peak Rockstar" survives on the leaderboard.
  - Neglect still kills an Old Fogey. The care check runs first.
- **Last Ember ranking.** The top `LAST_EMBER_GIFTS = 3` are the "This life" sharers on the leaderboard (`top_this_life`). Members banned at the time get no gift.
- **Talking.**
  - Wisp answers only in Wisp's House itself, not its threads, so Rhyme Duels stay separate. He answers members who mention him or reply to him.
  - Egg and Hatching get a canned wobble. Baby gets canned baby talk. Child and up get the AI.
  - Adult, Rockstar and Old Fogey sometimes chime in on their own.
  - Talking is not an interaction. It earns no bond and no happiness.
- **Memory notes and pickles.**
  - The AI reports a memory note and a pickle stance with trailing tags (`<note>…</note>`, `<pickles>love|hate</pickles>`). They are stripped from the visible reply.
  - Notes are kept and used from Adult on. The pickle stance is kept at any AI stage.
- **AI failure.** If every provider fails, Wisp says a canned `CHAT_FALLBACK` line and staff get one plain error per failure streak. This follows the spec's "never breaks" and "errors never hidden" together.
- **Leaderboard activation.** Opening `/wisp board` still activates a member. The Vault buttons do not.
- **Vault art.** `ASSETS/lunchbox.png` becomes `ASSETS/vault.png` (`git mv`). It is attached to the Vault post when the post is created, so it becomes the forum thumbnail.

## Review Focus

1. **Every AI provider is down, slow or rate-limited.** Wisp still answers with a canned line, within the timeout of each provider, and staff are told once per streak, not once per message. Tested in Task 6 by `test_all_providers_failing_raises_with_every_reason` and in Task 8 by `test_ai_outage_falls_back_and_reports_once`.
2. **Someone spams mentions at Wisp.** Only one AI call per member per `TALK_COOLDOWN`. The rest are ignored silently. Tested in Task 8 by `test_cooldown_stops_mention_spam`.
3. **The AI writes something it shouldn't.** That includes `@everyone`, role mentions, Unicode emoji, a wall of text, or a half-written tag. The posted reply has none of them and stays at most `AI_MAX_CHARS` long. Tested in Task 7 by the `test_parse_reply_*` group.
4. **The bot dies between the farewell and the next egg, or the farewell runs twice.** Each top sharer gets exactly one Last Ember, and exactly one coal egg is laid. Tested in Task 5 by `test_next_life_after_farewell_is_idempotent`.
5. **A late bloomer reaches day 45 or 60 still below Adult.** No Old Fogey and no farewell yet. He keeps growing normally. Tested in Task 2 by `test_late_bloomer_does_not_grow_old`.

- **Produces in `ai/chain.py`:**
  - `@dataclass(frozen=True) class Prompt: system: str; user: str` lives in `ai/prompt.py` and is re-exported from `ai/chain.py`. `wisp/voice.py` imports it from `ai.prompt`, so the pure layer never imports aiohttp.
  - `class ProviderError(Exception)`
  - `class AllProvidersFailed(Exception)` with `failures: list[tuple[str, str]]` holding (provider name, reason). Its `str()` lists every pair.
  - `class Provider(Protocol)`: `name: str`, and `async def complete(self, session: aiohttp.ClientSession, prompt: Prompt) -> str`. It raises ProviderError.
  - `GeminiProvider(model: str, api_key: str, base_url: str = "https://generativelanguage.googleapis.com/v1beta")`:
    - POSTs `{base_url}/models/{model}:generateContent`.
    - Sends header `x-goog-api-key`. The key never goes in the URL.
    - Body: `{"systemInstruction": {"parts": [{"text": system}]}, "contents": [{"role": "user", "parts": [{"text": user}]}], "generationConfig": {"maxOutputTokens": AI_MAX_OUTPUT_TOKENS}}`.
    - Result: join `candidates[0].content.parts[*].text`, skipping parts with `"thought": true`.
    - `name` is `f"gemini {model}"`.
  - `ChatProvider(name: str, url: str, model: str, api_key: str)` for OpenAI-style APIs:
    - Sends `Authorization: Bearer`.
    - Body: `{"model", "messages": [system, user], "max_tokens"}`.
    - Result: `choices[0].message.content`.
  - Every request sends `User-Agent: WispBot/1.0`. Groq refuses requests without one (Cloudflare 1010).
  - Every one of these is turned into `ProviderError`, so the next provider is tried:
    - a non-200 status (reason `"HTTP {status}"` plus the first 200 characters of the body),
    - `aiohttp.ClientError`,
    - `TimeoutError`,
    - a JSON shape error (`KeyError`, `IndexError`, `TypeError`, `ValueError`),
    - empty text.
  - `class AIChain(providers: Sequence[Provider])`:
    - `async complete(prompt: Prompt) -> str` tries each provider in order with `aiohttp.ClientTimeout(total=AI_TIMEOUT)`, and raises `AllProvidersFailed` (also when there are no providers).
    - It opens one `aiohttp.ClientSession` lazily and closes it in `async close()`.
  - `chain_from_config() -> AIChain` builds, in order:
    1. Gemini chat model
    2. Gemini fallback model
    3. Groq (`https://api.groq.com/openai/v1/chat/completions`)
    4. OpenRouter (`https://openrouter.ai/api/v1/chat/completions`)

    It skips any provider whose key or model is missing.
- **Produces in `app.py`:** `bot.ai = chain_from_config()`. `WispBot.close` also awaits `self.ai.close()`, in the same `finally` chain as the database close.
